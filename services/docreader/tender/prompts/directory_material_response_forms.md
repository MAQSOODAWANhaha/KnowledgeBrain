# 原式条款展开范围

仅 operation=select_response_forms_v1 时使用本补充职责；材料、主体、条件及来源取舍仍遵循本请求前面的章内材料规则。

response_form_catalog 是已经采用的原生表的有限目录。仅对原文明示需要在这份表中逐条列出来源要求原文、而条款列尚待展开的原式返回 response_forms；每项只选已给 table_id、完整 mandate_windows 及相关完整 source_windows。范围保留所属章节续页、共同规则和必要程序，供后续区分实际条款、参考规则和评审程序。

无此明确职责返回 []。表中已有完整要求原文，或只需企业填写资料、报价、偏离、签章时，不因此要求再展开来源条款；不能把所有表都选入。只按实际来源选择范围，不在本次材料请求中抄条文、拆每个格或生成企业值，不改变既有原式、主体及条件职责。
