# 参数展开

只处理本次给出的、至少25行的章节自身正文。章节已有其他子章时，本章自身的独立技术/服务要求仍须展开；不扩到未给出的子章正文。按原文中的小标题和参数条目给出每条的起始行、内容首行和结束行。不要抄写原文，不要合并相邻的独立参数。

每个 item 同时提供 title，作为完整、简短且不超过40字的参数业务名，概括该条完整指标或应答主题。不要使用条款首行、跨页残句、附件或条款编号、星号、宿主层级编号、句子和省略号；不能截取原文前若干字充当名称，也不能把源编号删空。title 只决定导航显示，原名和来源锚点由宿主保留，后面的所有正文、条件及证明义务仍按源窗口完整搬运，不因短标题删减。

只展开需要分别人工应答的技术/服务条目；原式、财务表、报价表的字段、签章文字、固定承诺以及填写说明不拆成新章。保留每条完整条件、证明材料、替代路径和时点，不能只取指标开头。宿主保留空白应答，不替投标人写接受、满足或承诺。

内容首行是该条正文的第一行，不一定是名称行。名称行和内容首行不同时，两者都要给出。现有 page/start_line/end_line/content_start_line 表示首段，四者在同一页且内容首行落在首段范围之内。

分页不等于条款结束。一个参数、证明要求或替代条件跨页时，首段仍用上述字段，后续正文按原顺序放在同一个 item 的 continuation_windows；每个续窗使用 document_id/page/start_line/end_line，同文件、前向、位于给定父正文内。没有续段返回 []。不要把上一页尚未结束的字词、条件或句子截成一项，再把续页残句另作一项；完整证据义务、替代路径和时点必须一起承载。

不同 items 不得重复拥有同一来源行。一原行同时承载相邻条件时，保留该完整原段作为联合应答位置，不为了拆项把同一行复制两次或切掉条件。不要选页眉、页码或本次没有给出的行。chapters 只返回本次请求的 chapter_id，最多一次；宿主保留完整父章和原表，不要求你誊写原文。

只返回 JSON，字段以宿主 Schema 为准。没有需要展开的条目时返回空 chapters。
