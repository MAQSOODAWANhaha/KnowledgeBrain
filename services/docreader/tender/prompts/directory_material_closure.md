# 原生载体来源差集闭合

仅 operation=select_source_closed_materials_v3 使用本补充职责，同时履行前述材料、原式条款选择和来源分册规则。

source_carrier_catalog 是本次 directory_cases 两候选中完整原生表的物理身份并集，每个 table_id 只列一次；origins 保留各 case_id、current/alternative 和 response_kind/subjects/entry 兼容签名。它是来源候选目录，不表示每个候选都必须提交，也不证明语义或主体份数充分。完整正文和原格已在本次来源输入中，宿主保留全部来源，不要誊写原文、格网或长身份。

先整体决定 directory_adjudications、assignments 和 source_groups。宿主应用整批结果后，实际已由采用章原生 part 承载的表自动记账，不需要回抄 carrier_dispositions。仅未承载的物理表必须明确返回一项 carrier_dispositions，选择给定 table_id 和 action：

- reference：chapter_id 指向一个 canonical 采用章，该章必须实际具有同源 native part，且与至少一个对应来源候选的响应角色、主体、提交 entry 兼容。纯文字出现不能代替原格；只选择一个章，不作全章交叉引用。可用 case_id 指定该表已有 origin。
- exclude：case_id 必须是本表给定 origin，且本 M 对该 case 的 directory_adjudications 已给出非空、有效的原件依据。宿主复用该依据，不新抄 basis_windows。错误候选或不适用范本可明确排除；语义正确性仍待核。已核 required_native 表不能普通 exclude，纠正原核定须另有 superseding review。
- unresolved：保留完整候选来源与具名待核，不宣布已完成。没有足够依据时可用此出口；不以无休止重试代替核定。不选择 chapter_id。

需要恢复原格时，优先使用本次已有 alternative 或完整 assignments；材料窗口必须完整覆盖原表。不要把后继要求阶段可能发现相同文字当作原表已经承载。物理表已出现仅证明 physical present；投标人和制造商等不同主体实例、独立正文义务仍需各自事实核定。新字段只表达本次语义处置，不抄宿主可推出的表目录、已有位置、编号或源文本。
