# 招标抽取分类研究：要求类型不等于检索路由

> 非规范性研究。保留早期分类调查的发现与推理，移除已废弃组卷/两类条款 schema 的施工建议。当前业务覆盖见 [PRD](../bidding/prd.md)，来源/候选边界见 [领域契约](../bidding/authoring.md)，正文编辑与出件见 [ONLYOFFICE](../bidding/onlyoffice.md)。研究不声明当前代码仍有相同缺陷。

## 1. 当时观察与适用边界

早期抽取将技术/商务同时用作条款分类和匹配路由：技术取产品资料，商务取公司资料。调查发现，这能解释资质、业绩与产品性能的检索去向，却不能表示完整招标要求。**不必为每类要求新建检索 Agent** 这一结论仍有价值；“因此报价/时间/程序要求无需抽取”的旧产品推论不再适用。

当前 PRD 已覆盖资格、评分、商务、技术、报价、项目组成员、目录/格式/签章/提交规则。要求分类用于组织响应与检查，不能因为没有知识检索命中就丢掉要求，也不能据业务分类无条件增加可见章节。

## 2. 保留的实证发现

以下是当时对 extraction policy、outline/coverage/reconcile 与合成 golden 的观察，不是要求恢复这些旧实现：

| 观察 | 产生的风险 | 仍适用的验证问题 |
| --- | --- | --- |
| 标题 skip 时，只有 family signal 或废标信号才能重新纳入候选 | 须知中的递交、交货、付款等义务可能丢失 | 要求是否覆盖当前完整文件，而不只覆盖关键词命中的句子？ |
| 报价不在 skip 提示中，但没有专属路由信号 | 报价/限价误送公司证照或产品参数检索，造成假缺件/假排名 | 无知识命中是否被误当作要求无效或我方不满足？ |
| “应/须/不得超过”触发宽，family signal 窄 | 无信号句被双路提出，平局默认技术并打冲突 | 是否保留歧义与待确认，而不是默认技术？ |
| 标题 prior 可能压过正文 | “技术要求”下的注册资本条件被误类 | 分类别只看标题，是否核对实际义务和来源？ |
| “条件”常被识别为标题后缀 | 总括句与其后列举义务可能没有拆开 | 每条需要响应的义务能否独立追溯？ |
| 键值表需完整连续 quote；表头只是上下文 | 单引“最大响应时间”不足以证明对应数值 | 来源定位是否包含行/单元格与原值、合并关系？ |
| 模型可从非候选 span 提出结果，而覆盖率只统计候选 | 指标显示完整仍可能漏抽或多抽 | 评估输入全集、未解析项和多余输出是否同时可见？ |

调查里的合成样例曾覆盖许可证废标句、注册资本、系统响应时间与中性库存表。它们能暴露分类/覆盖机制问题，但不能证明真实多文件投标质量，更不能证明 ONLYOFFICE 保存、排版或导出。

## 3. 不同要求如何区分

- **资格/资质/业绩**：主要由公司已有事实和材料支撑，不能混入产品排名。
- **产品规格/系统响应时间**：由产品资料支撑；“系统响应 2 秒”不是“交货 30 日”。
- **交货、付款、质保、实施安排**：本标响应可先拟议并待确认，不要求存在逐字证件。
- **报价/限价**：需要结构化价格与人工确认；不是新增一个证照检索 family 就能解决。
- **截止、有效期、程序与提交要求**：进入公共数据/编制规则/要求台账，不能因为不走产品匹配而丢弃。
- **评分/废标属性**：影响提示优先级与证明要求，不应变成禁止用户编辑或导出的业务闸门。

资料检索分类、招标法律篇章、响应数据与 DOCX 可见目录是不同概念。人员需独立数据不等于固定目录之外新增人员章；没有独立提交文件也不等于可以忽略招标分册要求。

## 4. 对照来源与后续核验

原调查基于当时的 extraction policy、coverage/outline/reconcile、API family 校验及三组合成 golden；这些旧路径与固定组卷实现不再是活动施工依据，不继续维护旧 schema/函数级清单。

法规仅用于确认招标内容广度，不直接决定数据库 enum 或产品新增功能：

- 财政部令第 87 号《政府采购货物和服务招标投标管理办法》第二十条：[中国政府网](https://www.gov.cn/zhengce/2017-07/11/content_5727444.htm)。包含资格资信、报价保证金、技术、合同、交付、支付、评标、无效情形与时间等。
- 《中华人民共和国招标投标法》第十九条：技术要求、资格审查标准、投标报价要求与评标标准。

后续核验应先检查转换原文、表格和 OCR，再检查要求覆盖与误分类，最后对照实际 DOCX 响应和证据。不以检索分类数量代替业务覆盖，也不照搬历史启发式或整套 Agent。
