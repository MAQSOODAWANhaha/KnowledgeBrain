## knowledge_required_v2真实验收

以[唯一字段合同](field-dictionary.md#编制最小修订knowledge_required_v2)及
[三批实施计划](implementation.md#knowledge_required_v2实施批次)为准。
隔离回归及真实验证分别记录在交接；下列清单保留真实模型、中文检索和文件品质验收，
不以旧v1回归或新隔离测试整体勾选。

第一批：检索意图、统一支持与调度。

- [ ] 现有大纲调用产生query及for_ids，query为业务文字且单条≤256字符；支持主题
  共享、复合要求多查询、source-only实际原文/表格，不以每事项两条为硬上限。
- [ ] supports正文只发送必要一份；support_ids正确回绑material_ids/source_refs，
  support_origins只控制允许来源。源文背景可保留，企业能力仍需知识支持；混合表单
  不重复，固定内容不覆盖，最终价格不代填；attachment_ids仅选择当前可判断的
  knowledge原件支持kN，不能将片段冒充证明。
- [ ] query按原值及范围去重，同执行单query回执复用且重绑当前目标；跨执行无法
  证明知识快照同版时重查。真实中文接口及分散片段召回可核对；缺意图、无命中及
  召回能力不足有真实诊断，不将本次未取得资料表述为知识库不存在资料。

第二批：选择性复核、一次修订及版本回退。

- [ ] 全人工/全无允许支持空位无写作和正文复核；有候选且完整返回的语义空稿仍有
  独立复核，可在资料足够且can_revise=true时补写一次；传输/预算失败空稿不追加
  无意义正文复核。混合单元覆盖有据内容及可能的漏匹配，不因空稿使R错误归零。
- [ ] 初审仅不可用保留未被否定草稿及待核原因；明确否定后生成S0，改稿失败/空回包
  或U1再核不可用均采用S0。新稿按新别名及新意见采用，未解决不循环改写，不复活
  已否定内容；多任务再核分批仍可替换各自意见，旧索引不误删新稿。
- [ ] a1精确定位仅移除对应附件；无可判断文字/原页不凭标题选为证明。无法精确定位
  仅影响明确任务的生成应答，固定模板、正确内容及其他任务保留，文件继续导出。
- [ ] 同执行恢复不重置四次额度；已完成结果不覆盖。新执行显式重审把真实feedback
  放入实际review和必要修订请求，空语义缓存不跳过独立复核；无清缓存、加盐或自动
  换ID重试。知识/公共依据变更的失效范围与实际复用请求可追溯。

第三批：真实中文知识库纵切，再扩展106页全文件。

  无型号功能应答、人工报价和实际附件；随后核对完整106页适用提交内容与DOCX。

  `4L`模型发送及`4Q`检索HTTP；
  新意图并入O，但旧17份来源回包不能充当新合同回包复用。逐阶段记录实际输入、
