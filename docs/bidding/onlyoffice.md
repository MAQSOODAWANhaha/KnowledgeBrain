# ONLYOFFICE：编辑、保存与同版导出

生成合同见 [大纲运行时](outline.md)。本页只写编辑器：大纲生成之后由 `response` 做知识库填充，然后编辑、保存、下载。不设独立正式编制或终稿升级。

## 正文与版本

DOCX 是正文主源。ONLYOFFICE 打开指定已保存版本，用户自由编辑；保存回调持久化后更新 current。不能只以浏览器已发送保存命令视为保存成功。

API 与编辑器通过版本、会话和用途绑定的授权访问文件与回调。保留过期会话、重复／乱序回调和并发保存的校验。具体配置、签名、缓存失效和回调协议见 [docx-editor.md](docx-editor.md)。

## AI 与用户内容

知识库填充是后续步骤，只读冻结的 `OutlineArtifact`。它不改章节，不改规定文字，也不把用户已保存的正文交给模型重写。编辑器里的正文以已保存的 DOCX 为准。生成或填充期间用户若已保存更新版本，不能覆盖那一版。

不把编译中间结构当成另一份正文主源。

## PDF 与报告

PDF 由同一已保存 DOCX 转换，输出绑定源身份。报告仅包含实际执行的检查和已知问题，不是未执行语义审查的批准。

## 部署与验证

保留现有服务 origin、CommandService origin、API origin、JWT／用途签名、字体及许可配置。实际镜像版本以当前部署配置为准，不使用历史方案中的旧 pin。

健康接口只证明服务可达；必须验证真实文件打开、编辑、保存、关闭重开、下载和同版 PDF。历史环境／许可记录不能当成当前生产验收。技术说明见 [接入文档](../../plans/bidding/onlyoffice-integration.md)。历史联调记录在 [archive](archive/README.md)，不是现行生成合同。
