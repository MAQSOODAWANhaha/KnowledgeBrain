## 结构性问题与通用修复

原结果有 **12 个模板记录**将相同文本范围重复标为固定文字、待填区、说明或签署位置。编译器按 region 输出实际内容，region 的 instruction 不是重写/脱敏指令；整页兼任多个角色会重复原文，且可能把示例投标人事实保留在固定文字中。

提取工具现在拒绝同一模板、同一文本来源中重叠的可编辑文本区域，返回冲突的 region 序号。相邻文本范围允许；网格以原来的单元格身份和角色校验，不把网格的整页证据范围误作文本重叠。编制恢复仍复用同一生产校验，因此历史空 findings、完整阅读台账和正确摘要不能豁免这个问题。没有新 schema、migration、来源解析器或业务关键词规则。

```sh
<构建目录>/debug/examples/tender_sample audit \

```
