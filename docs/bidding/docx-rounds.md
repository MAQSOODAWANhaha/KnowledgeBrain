# 投标文件版本、保存与发布

生成合同见 [大纲运行时](outline.md)。版本是编辑历史，不是草稿／终稿等级。

## 当前文件身份

工作区 current 指向具体版本与 DOCX 摘要。打开、保存、填充、导出均绑定具体身份，不能以当前章节标题替代版本身份。

ONLYOFFICE 回调持久化后才算保存成功；重复回调幂等，乱序／过期会话不能覆盖新版本。编辑器配置与保存协议详见 [docx-editor.md](docx-editor.md)。

## 生成与填充

保存和导出绑定具体版本与 DOCX 摘要。运行期间用户保存了新版本，不能用提交时的 expected 覆盖。

对象先暂存，事务内登记文件版本、current 和任务结果；同一发布重放返回同一收据，不创建额外版本。错误留下明确任务状态，已有 current 不受影响。

知识库填充读冻结大纲，不改写用户已保存的正文。成功后前端刷新 current；下载不得继续使用缓存的旧 version_id。

## 导出

下载指定已保存 DOCX；PDF 从同一 DOCX 转换，导出清单记录 source version_id、DOCX 摘要与输出摘要。后续编辑不改变历史导出，只使其不再代表当前版本。

不要求先进入旧正式编制或终稿复核。转换失败、保存未完成和文件损坏仍必须明确失败；报告仅陈述实际执行的检查。

## 验收

重复请求、重复和乱序回调、并发保存，以及同版 PDF，按本页的版本身份核对。历史运行记录在 [archive](archive/README.md)，不另设终稿复核门。
