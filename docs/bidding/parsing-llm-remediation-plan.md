# 解析与投标工作流改造方案入口

当前设计的唯一主线为 [Check执行闭环改造方案](../design/check-execution-plan.md)：包含当前能力/缺口、职责owner与输入输出、不变量、目录保留/拆分/移动/删除清单、接口、实施顺序和验收标准。已实现与planned严格分开。

当前范围为解析 → bidding提取 → 章节模板 → Check/repair。knowledge业务接入与材料匹配属于下一阶段；模块单元测试不代表已接入。原先把knowledge作为当前支撑线的规定已删除。

已实现的数据与工具契约见 [冻结输入](frozen-input.md)、[证据运行时契约](../design/evidence-runtime-contract.md)、[章节组织](outline.md)。这些文档维护接口事实，不另立任务完成标准。

真实服务验收尚未通过。当前本地修复与通用测试只证明执行及证据契约；私有真实验收材料和输出单独保留。没有迁移兼容路径，未授权合并或部署。
